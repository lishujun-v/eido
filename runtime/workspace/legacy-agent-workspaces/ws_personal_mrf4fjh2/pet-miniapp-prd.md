# 宠物生活小程序 PRD

> 版本：v1.0 | 日期：2025-01

---

## 一、背景与目标

### 1.1 背景

国内养宠人群持续增长，宠物已从"看门/抓老鼠"角色转变为家庭成员。但养宠过程中存在大量碎片化需求：健康记录散落、社区内容分散在多平台、线下服务（寄养/遛狗/洗护）信息不透明。

### 1.2 目标

打造一个微信小程序，围绕宠物主人的日常生活场景，提供：

- **记录**：宠物健康档案与日常提醒
- **社交**：宠物社区分享与互动
- **服务**：周边宠物服务发现与预约

核心指标：
- 上线3个月内注册用户 ≥ 1万
- 社区内容月发布量 ≥ 3000条
- 服务预约转化率 ≥ 15%

| 画像 | 特征 | 核心需求 |
|------|------|----------|
| **新手铲屎官** | 刚养宠物，缺乏经验 | 养宠知识、健康提醒、医疗求助 |

## 五、核心交互流程

### 5.1 新用户首次使用流程

```
打开小程序
  → 微信授权登录
  → 引导创建宠物档案（名称/种类/品种/生日/体重/头像）
  → 进入首页（社区动态流）
```

### 5.2 发布社区动态

```
首页点击「+」发布按钮
  → 选择图文/视频
  → 编辑内容
  → 添加话题标签（可选）
  → 选择关联宠物（可选）
  → 发布
  → 返回首页，动态出现在信息流
```

### 5.3 健康提醒流程

```
宠物档案页 → 添加健康记录（类型/日期/下次提醒日期）
  → 系统根据「下次提醒日期」设置推送
  → 到期前7天/3天/1天 → 微信服务通知推送
  → 用户点击通知 → 跳转档案页查看详情
```

### 5.4 服务预约流程

```
底部Tab「服务」
  → 服务列表（筛选类型/距离）
  → 点击商家 → 商家详情页
  → 选择服务项目
  → 选择预约时间
  → 选择宠物（自动带出已建档案）
  → 确认提交预约
  → 商家确认 → 订单状态更新
  → 到店服务 → 完成订单
```

## 六、验收标准

### 6.1 宠物档案

- 可创建至少1个宠物档案，字段完整校验
- 健康记录可重复添加，按时间倒序展示
- 提醒功能：到期前正确触发推送，不漏发不重复

### 6.2 社区

- 图文/视频均可正常发布与展示
- 信息流加载流畅，支持下拉刷新、上拉加载
- 点赞/评论/收藏实时生效，数据准确

### 6.3 服务

- 服务列表按距离排序正确
- 预约订单全流程状态流转正确
- 订单状态变更可被用户及时感知（消息推送）

### 6.4 通用

- 微信登录流程顺畅，无多余授权步骤
- 页面加载时间 ≤ 2秒
- 各页面空状态有引导提示

## 七、非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 首屏加载 ≤ 2s，列表滑动无卡顿 |
| 兼容性 | 微信小程序基础库 ≥ 2.10，iOS/Android 双端兼容 |
| 安全 | 用户数据加密存储，不泄露隐私信息 |
| 可用性 | 服务可用性 ≥ 99.5% |
| 扩展性 | 后端模块化设计，支持后续新增服务类型 |
| 推送 | 依赖微信订阅消息能力，需用户主动授权订阅 |
