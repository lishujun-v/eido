# 专注看板运行数据

看板会把需求、任务、每日进展和界面设置持久化到同目录下的 `storage.json`。

- `storage.json` 由 Eido 运行时自动创建和更新。
- 数据采用 UTF-8 JSON 格式，可直接复制备份。
- 浏览器 LocalStorage 仅作为首次迁移和写入失败时的兜底。
- 磁盘与浏览器兜底数据都带有更新时间；重新打开时会采用较新的一份，随后同步回磁盘。
- 从旧版本升级时，如果磁盘文件没有任务，会检查看板键和 Eido 宿主旧键中的浏览器副本；发现旧任务后会优先恢复并写入磁盘。
- `storage.json` 已被 `.gitignore` 排除，不会与项目源代码一起提交。
