# 原型决策记录

版本：v0.1

选定原型：Open Identity Network

参考图：

- [assets/eido-home-prototype-v1.png](./assets/eido-home-prototype-v1.png)

## 采用原因

这个方向最适合作为 MVP 的主视觉和首页开发参考，因为它同时表达了两个核心动作：

- 用一句话搜索并发现合适的人
- 创建自己的数字分身，让别人通过 Agent 认识自己

它不像传统招聘网站，也不像普通 AI 聊天工具，更接近“可对话的个人主页网络”。

## 需要保留的设计特征

- 简约明亮的浅色背景
- 顶部清晰导航
- 大号自然语言搜索框作为首页核心
- 明确的“创建我的 Agent”入口
- 热门技能标签
- 推荐 Agent 卡片
- 右侧 Agent 对话预览
- “数字代理”标签
- “等待主人确认”状态提示
- 底部可信提示：身份已认证、信息由本人管理、公开可被发现

## 开发时需要简化的地方

- 整体再简约一些，减少装饰和不必要模块
- Agent 卡片信息控制在 2-3 行内
- 右侧对话预览保持轻量，不喧宾夺主
- 首页第一屏优先保证搜索和创建入口
- 移动端优先把搜索、创建入口和推荐 Agent 串成单列

## 第一轮页面范围

先按该风格实现：

1. 首页
2. Agent 卡片组件
3. Agent 对话预览组件
4. 热门技能标签组件
5. 基础导航

暂不在第一轮实现完整后台、搜索结果页和真实对话逻辑。

## 下一步

进入工程初始化，并先做静态 UI 骨架：

```text
Next.js 项目
-> UI tokens
-> 首页静态实现
-> AgentCard 组件
-> ConversationPreview 组件
-> 响应式适配
```

静态 UI 跑通后，再接入数据模型、搜索和对话流程。
