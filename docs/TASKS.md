## Phase 1：项目初始化

目标：搭建可运行的 Web 应用基础。

任务：

- 初始化 Next.js + TypeScript 项目
- 配置 Tailwind CSS
- 建立基础布局和路由
- 初始化 Prisma
- 配置 PostgreSQL 连接
- 创建基础 UI 组件
- 配置环境变量模板

验收：

- 本地开发服务可以启动
- 首页可以访问
- 数据库可以连接
- Prisma migration 可以运行

## Phase 2：用户账号

目标：用户可以注册、登录和保持会话。

任务：

- 邮箱注册
- 邮箱登录
- 退出登录
- 当前用户接口
- 登录态页面保护
- 基础错误提示

验收：

- 用户可以创建账号
- 用户可以登录和退出
- 未登录用户不能进入后台

## Phase 3：Agent 创建与管理

目标：用户可以创建并管理自己的数字分身。

任务：

- Agent 数据模型
- AgentProfile 数据模型
- ContactMethod 数据模型
- AgentRule 数据模型
- 创建 Agent 表单
- 编辑 Agent 表单
- 保存草稿
- 发布 Agent
- 暂停接收请求
- 我的 Agent 后台概览

验收：

- 用户可以创建一个 Agent
- 用户可以编辑 Agent 资料
- 用户可以发布 Agent
- 发布后生成公开 slug
- 用户只能管理自己的 Agent

## Phase 4：Agent 公开主页

目标：外部用户可以访问已发布 Agent 的主页。

任务：

- Agent 公开主页路由
- 公开字段展示
- 隐私字段过滤
- Agent 状态展示
- 发起对话入口
- 举报入口占位

验收：

- 已发布 Agent 可以公开访问
- 未发布 Agent 不能被外部访问
- 私密联系方式不会展示
- 暂停状态下不能发起新对话

## Phase 5：搜索 Agent

目标：用户可以通过自然语言找到 Agent。

任务：

- 搜索页
- 搜索 API
- Agent searchableText 生成
- 基础关键词和标签搜索
- 城市、状态过滤
- 搜索结果卡片
- 匹配原因生成，先用规则生成
- 预留 embedding 字段和接口

验收：

- 用户可以输入需求搜索 Agent
- 搜索结果展示匹配 Agent
- 结果包含名称、简介、标签、城市、匹配原因
- 暂停和未发布 Agent 不出现在结果中

## Phase 6：对话系统

目标：访问者可以和 Agent 进行初步沟通。

任务：

- Conversation 数据模型
- Message 数据模型
- 创建对话 API
- 对话页
- 消息发送和存储
- Agent 回复生成接口
- Agent 身份声明
- 对话状态管理

验收：

- 用户可以从 Agent 主页发起对话
- 消息可以正常发送和展示
- Agent 会以数字代理身份回复
- 对话记录可以持久化

## Phase 7：Agent 回复与安全边界

目标：Agent 能基于主人资料回复，并避免越权。

任务：

- 构建 Agent 对话上下文
- 接入 LLM API
- Agent system prompt
- 隐私字段过滤
- 联系方式请求识别
- 报价、线下见面、合作意向识别
- 越权回复拦截
- 不确定问题转真人确认

验收：

- Agent 回复基于主人资料
- Agent 不直接泄露私密联系方式
- Agent 不代表主人承诺价格、时间、线下见面
- 触发敏感条件时创建接入请求

## Phase 8：真人接入

目标：主人可以处理 Agent 转交的高价值或高风险请求。

任务：

- HandoffRequest 数据模型
- 接入请求创建
- 接入请求列表
- 接入请求详情
- 对话摘要
- 主人接入
- 主人拒绝
- 让 Agent 继续沟通

验收：

- Agent 可以触发接入请求
- 主人可以看到请求摘要和完整对话
- 主人可以接入对话
- 主人接入后对方能看到真人已加入
- 主人可以拒绝请求

## Phase 9：举报、拉黑与频率限制

目标：提供 MVP 级别的防骚扰能力。

任务：

- Report 数据模型
- Block 数据模型
- RateLimitEvent 数据模型
- 举报弹窗
- 拉黑操作
- 发起对话频率限制
- 单会话消息频率限制
- 被拉黑后禁止继续联系

验收：

- 用户可以举报 Agent 或对话
- 主人可以拉黑请求方
- 被拉黑对象不能继续发消息
- 高频请求会被限制

## Phase 10：体验打磨与验收

目标：让 MVP 可以用于小范围试用。

任务：

- 空状态补齐
- 错误状态补齐
- Loading 状态补齐
- 移动端适配
- 表单校验
- 基础测试
- 种子 Agent 数据
- README 使用说明

验收：

- 核心链路可以完整跑通
- 页面在桌面和移动端可用
- 新用户能完成创建 Agent
- 访问者能搜索、对话并触发真人接入

## 第一轮开发建议

先做这 4 件事：

1. 初始化项目
2. 建立数据库和 Prisma schema
3. 实现 Agent 创建、编辑、发布
4. 实现 Agent 公开主页

这四步做完，产品就有了第一个可展示的骨架。
