# 数字分身 Agent 平台低保真原型说明

版本：v0.1

状态：草案

关联文档：

- [PRD.md](./PRD.md)
- [MVP_SPEC.md](./MVP_SPEC.md)

## 1. 原型目标

本文件定义 MVP 阶段的页面结构、核心组件、关键交互和页面流转。

低保真原型的目标是先回答：

- 用户如何快速理解平台价值？
- 用户如何创建一个可信的数字分身？
- 访问者如何找到合适的 Agent？
- 访问者如何和 Agent 对话？
- Agent 如何触发真人接入？
- 主人如何处理接入请求？

## 2. MVP 页面清单

P0 页面：

- 首页
- 注册 / 登录页
- 创建 Agent 流程页
- Agent 公开主页
- 搜索结果页
- Agent 对话页
- 我的 Agent 后台
- 接入请求详情页

P1 页面：

- 设置页
- 举报页 / 举报弹窗
- 拉黑列表
- 对话历史页
- 管理员基础审核页

## 3. 全局导航

### 3.1 未登录状态

导航元素：

- 产品 Logo
- 搜索入口
- 探索 Agent

### 3.2 已登录状态

用户头像菜单：

- 对话历史

- 退出登录

## 4. 首页

### 4.1 页面目标

首页需要同时服务两类用户：

- 想找人的访问者
- 想创建自己数字分身的新用户

首页第一屏要让用户明确知道：

```text
这里可以通过 Agent 找到人，也可以创建自己的数字分身让别人找到你。
```

### 4.2 页面结构

```text
[全局导航]

[主搜索区]
标题：让世界通过 Agent 认识你
副标题：创建你的数字分身，或用一句话找到你想认识的人。

[自然语言搜索框]
占位示例：帮我找一个会修复古摩托车的人，最好在上海。
[搜索按钮]
[创建我的 Agent 按钮]

[热门搜索标签]
AI 产品 / 摩托车维修 / 品牌设计 / 短视频剪辑 / 创业合伙人 / 本地服务

[推荐 Agent 区]
Agent 卡片列表

[平台价值区]
创建数字分身 / 被别人发现 / Agent 初步沟通 / 真人接入
```

### 4.3 核心组件

搜索框：

- 支持自然语言输入
- 回车触发搜索
- 空输入时点击搜索提示用户输入需求

Agent 卡片：

- 头像
- 名称
- 一句话介绍
- 能力标签
- 城市
- 可联系状态
- 查看主页按钮

### 4.4 关键交互

- 输入需求并搜索：进入搜索结果页
- 点击热门标签：带着标签进入搜索结果页
- 点击推荐 Agent：进入 Agent 公开主页
- 点击创建我的 Agent：
  - 未登录：进入登录页
  - 已登录且无 Agent：进入创建流程
  - 已登录且已有 Agent：进入我的 Agent 后台

### 4.5 空状态

如果暂无推荐 Agent：

```text
还没有足够多的公开 Agent。你可以成为第一批创建数字分身的人。
```

## 5. 注册 / 登录页

### 5.1 页面目标

让用户快速创建账号或登录，并回到原本任务。

### 5.2 页面结构

```text
[Logo]

[登录 / 注册切换]

邮箱
密码

[登录按钮 / 注册按钮]

[忘记密码]

[服务协议和隐私政策提示]
```

### 5.3 MVP 支持

- 邮箱注册
- 邮箱登录
- 密码登录

### 5.4 关键交互

- 从创建 Agent 入口进入：登录后继续创建流程
- 从对话入口进入：登录后回到目标 Agent 对话页
- 注册完成后：默认进入创建 Agent 流程

### 5.5 错误状态

- 邮箱格式错误
- 密码长度不足
- 账号不存在
- 密码错误
- 邮箱已注册

## 6. 创建 Agent 流程页

### 6.1 页面目标

引导用户创建一个完整、可信、可对话的数字分身。

### 6.2 总体结构

```text
[顶部进度条]
基础信息 -> 能力经历 -> 性格兴趣 -> 联系方式 -> 行为边界 -> 预览发布

[当前步骤表单]

[上一步] [保存草稿] [下一步]
```

### 6.3 步骤一：基础信息

字段：

- Agent 名称
- 头像
- 一句话介绍
- 所在城市
- 职业身份
- 语言
- 时区

提示文案：

```text
这个 Agent 会作为你在线上的数字代理出现。建议使用别人能识别你的名称和真实能力描述。
```

校验：

- Agent 名称必填
- 一句话介绍必填
- 城市建议填写

### 6.4 步骤二：能力与经历

字段：

- 核心能力
- 技能标签
- 行业领域
- 可提供的帮助
- 项目经历
- 代表作品链接
- 可服务方式：线上 / 线下 / 都可以

辅助问题：

- 你最希望别人因为什么能力找到你？
- 你可以帮助别人解决什么问题？
- 有没有可以证明你能力的作品、链接或经历？

### 6.5 步骤三：性格与兴趣

字段：

- 性格描述
- 沟通风格
- 兴趣爱好
- 价值观
- 想认识什么样的人
- 不希望被什么事情打扰

沟通风格选项：

- 专业直接
- 友好温和
- 简洁高效
- 轻松幽默
- 谨慎保守

### 6.6 步骤四：联系方式与可见性

字段：

- 站内私信，默认开启
- 邮箱
- 微信
- 电话
- 个人网站
- 社交媒体
- 预约链接

每个联系方式支持可见性：

- 不填写
- 公开可见
- 登录后可见
- 主人确认后可见
- 永不由 Agent 透露

MVP 默认：

- 联系方式默认“主人确认后可见”
- 站内对话默认开启

### 6.7 步骤五：行为边界

字段：

- 是否允许陌生人发起对话
- 每日最多接收陌生请求数
- 是否允许 Agent 分享联系方式
- 是否允许 Agent 报价
- 是否允许 Agent 承诺时间
- 是否允许 Agent 安排线下见面
- 是否允许讨论敏感话题
- 触发真人接入的条件
- 自动拒绝的话题
- 屏蔽关键词

默认设置：

- 允许陌生人发起对话：开启
- 分享联系方式：关闭
- 报价：关闭
- 承诺时间：关闭
- 安排线下见面：关闭
- 敏感话题：关闭
- 明确合作意向时触发接入：开启
- 请求联系方式时触发接入：开启
- 线下见面时触发接入：开启

### 6.8 步骤六：预览发布

页面展示：

- Agent 公开主页预览
- 可公开字段列表
- 私密字段列表
- 行为边界摘要

按钮：

- 返回编辑
- 保存草稿
- 发布 Agent

发布后：

```text
你的数字分身已上线。
公开主页链接：/agents/{slug}
```

### 6.9 草稿和离开保护

要求：

- 每步自动保存草稿
- 用户离开未保存页面时提示
- 已发布 Agent 再编辑时不影响旧数据，保存后更新主页

## 7. Agent 公开主页

### 7.1 页面目标

让访问者在 30 秒内理解：

- 这个人是谁
- 擅长什么
- 是否值得联系
- 可以如何开始对话

### 7.2 页面结构

```text
[Agent 头部]
头像 / 名称 / 数字代理标识 / 城市 / 职业 / 可联系状态

[一句话介绍]

[发起对话按钮]

[能力标签]

[可提供帮助]

[经历与作品]

[想认识的人]

[沟通风格和兴趣]

[联系方式区域]
根据可见性展示或提示需要主人确认

[安全提示]
该页面由用户创建，Agent 是数字代理，不代表平台背书。

[举报入口]
```

### 7.3 状态展示

Agent 状态：

- 可联系
- 忙碌
- 暂停接收请求

如果暂停接收请求：

- 发起对话按钮置灰
- 展示提示：该 Agent 当前暂停接收新请求

### 7.4 关键交互

- 点击发起对话：进入 Agent 对话页
- 点击作品链接：新窗口打开
- 点击举报：打开举报弹窗
- 点击请求联系方式：
  - 如果公开：直接展示
  - 如果需确认：进入对话并触发确认流程

### 7.5 空字段展示

如果某些资料未填写，不显示空模块。

如果 Agent 资料过少，展示：

```text
这个 Agent 的主人还没有完善更多资料。
```

## 8. 搜索结果页

### 8.1 页面目标

让用户从自然语言需求中找到可能合适的人。

### 8.2 页面结构

```text
[搜索框]
原始需求文本

[解析结果]
能力：摩托车维修
地点：上海
方式：线下
意图：寻找服务

[过滤器]
城市 / 线上线下 / 可联系状态 / 认证状态

[结果列表]
Agent 卡片
匹配度
匹配原因
[查看主页] [发起对话]
```

### 8.3 Agent 结果卡片

字段：

- 头像
- 名称
- 简介
- 能力标签
- 城市
- 可联系状态
- 匹配度
- 匹配原因

### 8.4 关键交互

- 修改搜索词并重新搜索
- 调整过滤器刷新结果
- 点击 Agent 卡片进入主页
- 点击发起对话进入对话页

### 8.5 空结果

文案：

```text
暂时没有找到完全匹配的 Agent。你可以放宽地点或能力条件，也可以发布你的需求，让合适的人稍后联系你。
```

MVP 暂不做“发布需求”，但可以保留入口为后续扩展。

## 9. Agent 对话页

### 9.1 页面目标

让访问者和数字分身完成初步沟通，同时清楚知道当前是否真人参与。

### 9.2 页面结构

```text
[对话顶部]
Agent 头像 / 名称 / 数字代理标识 / 查看主页 / 举报

[身份提示条]
我是 XX 的数字代理，可以帮你了解他/她，并进行初步沟通。

[对话消息区]

[快捷问题]
你能提供什么帮助？
你现在是否方便接项目？
我想联系你的主人。

[输入框]
[发送按钮]

[请求真人接入按钮]
```

### 9.3 消息类型

- 访问者消息
- Agent 消息
- 系统提示
- 主人消息

系统提示示例：

```text
Agent 已将你的请求转给主人确认。
```

```text
主人已接入对话。
```

### 9.4 Agent 首次回复

首次回复必须包含身份声明：

```text
你好，我是 XX 的数字代理，可以根据他/她授权的资料进行初步沟通。涉及联系方式、报价、线下见面或具体承诺时，我会请主人确认。
```

### 9.5 触发真人接入

触发后页面状态：

```text
已请求主人接入。你可以继续补充信息，Agent 会把摘要一起转给主人。
```

触发原因：

- 用户点击请求真人接入
- 用户索要联系方式
- 用户提出合作
- 用户提出报价
- 用户提出线下见面
- Agent 不确定答案

### 9.6 对话终止

终止原因：

- 命中拒绝规则
- 对方被拉黑
- 频率过高
- Agent 暂停接收请求

终止文案：

```text
这个请求暂时无法继续。你可以调整问题后重试，或寻找其他 Agent。
```

## 11. 接入请求详情页

### 11.1 页面目标

让主人快速判断是否接入对话。

### 11.2 页面结构

```text
[请求摘要]
对方是谁
对方想做什么
Agent 为什么建议接入
风险提示

[对话摘要]
关键上下文

[完整对话记录]

[操作区]
接入对话
拒绝
让 Agent 继续沟通
拉黑
举报
```

### 11.3 请求摘要字段

- 请求类型
- 匹配原因
- 对方需求
- 已知条件
- 缺失信息
- Agent 建议
- 风险等级

### 11.4 操作结果

接入：

```text
主人已接入对话。
```

拒绝：

```text
主人暂时不方便继续该请求。
```

继续沟通：

```text
Agent 将继续向对方补充询问信息。
```

拉黑：

```text
对方将无法继续联系你的 Agent。
```

## 13. 关键状态与空状态

### 13.1 用户未创建 Agent

我的 Agent 页面展示：

```text
你还没有创建自己的数字分身。创建后，别人就可以通过 Agent 认识你、找到你。
```

按钮：

- 创建我的 Agent

### 13.2 Agent 未发布

后台展示：

```text
你的 Agent 还未发布。发布后才会拥有公开主页，并可以被搜索到。
```

按钮：

- 继续完善
- 预览
- 发布

### 13.3 暂无待处理请求

```text
暂时没有需要你处理的请求。Agent 会在遇到高匹配或需要你确认的情况时通知你。
```

### 13.4 暂无对话历史

```text
还没有人和你的 Agent 对话。你可以先分享自己的公开主页。
```

## 14. 关键交互流转图

### 14.1 创建并发布 Agent

```text
首页
-> 创建我的 Agent
-> 登录 / 注册
-> 创建流程
-> 预览
-> 发布
-> Agent 公开主页
```

### 14.2 搜索并发起对话

```text
首页搜索
-> 搜索结果页
-> Agent 公开主页
-> 发起对话
-> Agent 对话页
```

### 14.3 Agent 触发主人接入

```text
Agent 对话页
-> 命中接入条件
-> 生成接入请求
-> 主人后台待处理请求
-> 接入请求详情
-> 主人接入
-> 对话页显示主人已加入
```

### 14.4 拒绝或拉黑

```text
对话 / 请求详情
-> 主人拒绝或拉黑
-> 对话状态更新
-> 访问者收到系统提示
```

## 15. MVP 视觉方向建议

### 15.1 产品气质

建议整体气质：

- 可信
- 清晰
- 轻社交
- 有一点未来感
- 不像传统招聘网站
- 不像纯工具后台

### 15.2 UI 风格

建议：

- 信息密度适中
- 卡片用于 Agent 列表和请求列表
- Agent 主页更像个人主页，而不是表单
- 对话页要清楚区分 Agent 和真人
- 隐私、接入、风险提示要低调但明确

### 15.3 关键视觉符号

建议强化：

- 数字代理标识
- 可联系状态
- 真人已接入状态
- 需要主人确认的私密信息
- 匹配原因
