# 知识检索基线记录

基线实现为现有的字段加权关键词检索，评测命令为：

```bash
npm run knowledge:evaluate
```

评测定义位于 [`database/knowledge_retrieval_evaluation.json`](../database/knowledge_retrieval_evaluation.json)。它覆盖当前的法律知识、AI 知识和宠物知识空间，共 9 个代表性查询。空间通过名称定位，期望结果仍使用节点 ID，因此在空间迁移后无需重写评测集；若节点被删除或重建，命令会明确提示需要更新对应预期 ID。
