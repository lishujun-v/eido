你想支持哪些动画类型？

选择你需要的动画类型（可多选）

A

粒子特效

粒子爆炸、烟花、下雪、星空、粒子跟随鼠标等

B

CSS 关键帧动画

弹跳、旋转、淡入淡出、滑动、缩放、变色等过渡动画

C

Canvas 绘制动画

波形图、分形、流体模拟、万花筒、动态图表等

D

SVG 路径动画

描边动画、路径变形、图标动效、logo 动画等

E

3D / WebGL 动画

Three.js 3D 场景、旋转模型、光影效果等

F

文字动画

打字机效果、文字飞入、逐字高亮、标题大屏动效等

G

物理模拟

重力、碰撞、弹簧、布料、流体等物理效果

H

全部都要

不限制类型，Agent 根据描述自行判断最合适的实现方式

用户说"做一个烟花动画"

<!DOCTYPE html>
<html>
  <canvas id="c"></canvas>
  <script>
    // 烟花粒子系统
    const particles = [];
    // ... 爆炸逻辑
  </script>
</html>
