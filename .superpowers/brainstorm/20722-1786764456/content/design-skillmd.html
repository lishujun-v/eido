设计 · 第 3 部分：SKILL.md 指令设计

Agent 执行这个 skill 时要遵循的完整流程

SKILL.md 核心内容

1. 触发条件

用户说"做动画"、"生成动画"、"把这段文字做成动画"、"做一个XX的演示动画"等

2. 确认最小信息（缺省直接采用）

  • 风格：缺省"现代简约、深色背景"
  • 画幅：缺省 16:9
  • 时长：缺省 Agent 根据故事长度自动判断
  • 语言：缺省跟随用户输入语言

3. 场景拆分指南

  • 按叙事节奏拆分：开头 → 展开 → 高潮 → 结尾
  • 每场景 1 个核心信息点，旁白控制在 2-4 句
  • 每场景建议时长 3-15 秒
  • 标注每场景的视觉描述和建议动画类型

4. 动画类型选择指南

粒子效果 → 烟花、星空、雨雪、魔法
CSS 动画 → 元素入场、弹跳、强调
Canvas → 波形图、数据可视化、绘画
SVG → 图标动效、路径描边、logo
3D/WebGL → 产品旋转、空间展示
文字动画 → 打字机、标题大屏、逐字
物理模拟 → 重力、碰撞、弹性

5. 组装与输出

  • 读取 player/template.html 骨架
  • 将 scenes 数据 + 场景 HTML 注入模板
  • 音频文件放在输出目录的 audio/ 子目录
  • 单场景 → 单个 HTML；多场景+音频 → 目录输出
  • 默认输出到 workspace/html-animation/

6. TTS 集成

  • 每场景旁白调用 kokoro-text-to-speech 生成 WAV
  • 使用 zf_xiaobei 中文语音，默认语速 1.0
  • 音频文件名：scene-{index}.wav
  • 音频时长作为该场景的 duration
