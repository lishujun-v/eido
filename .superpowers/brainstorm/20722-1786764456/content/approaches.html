实现方案对比

三种方案，各有侧重

方案概览

A

纯 Agent 生成 · 零依赖

SKILL.md 提供详细的场景拆解 + 动画编写指南，Agent 从零手写 HTML/CSS/JS。不依赖任何外部框架，生成的动画文件完全自包含。

B

模板 + Agent 填充

预置 3-5 个经典动画模板（产品演示模板、数据故事模板、通用叙事模板），Agent 分析故事后选模板，填入内容并调整参数。

C

轻量框架 + Agent 编排

Skill 自带一个极简的"动画播放器"引擎（场景管理、转场、字幕同步、TTS 对齐），Agent 只需生成每个场景的内容片段，引擎负责串联播放。

详细对比

方案 A：纯 Agent 生成

优点

  • 零外部依赖，单文件即用
  • 最灵活，任何效果都能做
  • SKILL.md 就是全部

缺点

  • 质量依赖模型能力
  • 长动画可能结构混乱
  • 每次生成差异大
方案 B：模板 + 填充

优点

  • 输出质量稳定可控
  • 场景结构清晰
  • 适合常见场景

缺点

  • 模板覆盖有限
  • 特殊需求难以适配
  • 需要维护模板
方案 C：引擎 + 编排

优点

  • 播放体验统一（进度条/暂停/倍速）
  • TTS 字幕同步精准
  • Agent 只需关注内容
  • 场景切换动画统一

缺点

  • 需要开发播放器引擎
  • 引擎文件需随 skill 分发
  • 可能限制创意自由度

⭐ 推荐：A + C 混合

以 方案 C 的播放器引擎 为骨架，提供统一的播放体验。Agent 在每个场景内部自由使用 方案 A 的能力（粒子、Canvas、SVG 等），不受引擎限制。

引擎处理：时间线、场景切换、TTS 同步、字幕、播放控制
Agent 处理：每个场景的具体动画内容
