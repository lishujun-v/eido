Skill 目录结构 + 工作流

Skill 目录结构

powers/skills/html-animation/
├── SKILL.md  ← Agent 执行的指令
└── player/
    ├── template.html  ← 播放器 HTML 骨架
    ├── player.css  ← 播放器样式
    └── player.js  ← 播放器引擎

工作流（5 步）

1
解析故事 → 拆分为场景序列，每场景包含：旁白文本、视觉描述、建议动画类型、预估时长
2
生成场景内容 → 每个场景生成独立的 HTML 片段（Canvas/CSS/SVG 动画）
3
生成 TTS 音频 → 调用 kokoro-text-to-speech，每场景生成一段 WAV 旁白
4
组装 → 把场景片段 + 音频 + 字幕注入播放器模板，生成完整 HTML
5
输出 → 保存到 workspace/ 或用户指定路径，告诉用户用浏览器打开
